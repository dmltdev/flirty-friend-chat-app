⏺ Plan — detectWordPairViolations(text, rules)

  Pipeline:
  1. Normalize (char-level, keep orig→norm index map):
    - NFKD → strip combining marks, zero-width chars
    - Lowercase
    - Leet map: 0→o, 1→i, 3→e, 4→a, 5→s, 7→t, 8→b, 9→g, @→a, $→s, !→i, +→t, |→i,
   €→e, £→l, ¥→y
    - Collapse tripled+ letter runs → 2 (druuugs→druugs); keep doubles (don't
  over-squash)
    - Replace non-alphanumeric (incl. punctuation, symbols) with single space
    - Collapse whitespace
  2. Tokenize normalized string into words w/ start/end offsets.
  3. De-spacing pass: also produce a "glued" variant where runs of ≤2-char
  tokens are concatenated into one token (handles b u y, d.r.u.g.s). Keep
  original token indices it spans.
  4. Match each rule:
    - For w1/w2 (normalized same way), find all token indices where token === 
  target OR token.includes(target) (substring match catches xbuyx).
    - For every (i, j) with |i−j| ≤ maxDistance AND i ≠ j, emit
  WordPairViolation { w1Index: i, w2Index: j, distance: |i−j| }.
    - Dedupe by (rule, i, j).
  5. Return sorted by earliest index.

  Files:
  - src/app/features/moderation/word-pair/normalize.ts — normalization +
  tokenize
  - src/app/features/moderation/word-pair/detect.ts — detectWordPairViolations
  - src/app/features/moderation/word-pair/normalize.test.ts, detect.test.ts
  (vitest)

  Unresolved questions

  1. Directionality: is drugs … buy a violation, or only buy … drugs? (Rules
  don't say; I'd default to unordered.)
  2. Distance definition: words between w1 and w2, or absolute index diff?
  maxDistance:3 with "buy X Y Z drugs" — violation or not? (I'd use index diff,
  so that example = distance 4, no.)
  3. Substring match policy: allow buy inside buyer/buying? Risks false
  positives but catches buyz/drugz. (I'd allow; moderation prefers recall.)
  4. Token-index semantics: indices into the normalized token array, or mapped
  back to original char offsets? (w1Index/w2Index naming suggests token
  indices.)
  5. Leet ambiguity: 1→i or 1→l? |→i or |→l? Run both variants, or pick one?
  6. Cross-word leet: e.g., hack as h4ck inside h4ck3r — substring match
  handles. OK?
  7. Max input length / perf budget?
